# Jotirmoy Bhowmik — Portfolio

Personal portfolio for [Jotirmoy Bhowmik](https://jotirmoy.vercel.app) — backend engineer / full-stack developer (NestJS, TypeScript, APIs, microservices).

## Stack

- Next.js (App Router)
- TypeScript
- Lenis + Motion

## Local

```bash
npm install
npm run dev
```

## Production

```bash
npm run build
npm start
```

Set in Vercel (Project → Settings → Environment Variables):

```
NEXT_PUBLIC_SITE_URL=https://jotirmoy.vercel.app
```

Use your custom domain there when you attach one.
